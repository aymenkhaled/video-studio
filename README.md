# video-studio

Code-driven video production: Remotion (2D, 3D via three.js, maps), a Python audio pipeline, and distributed rendering on GitHub Actions.

- Rules: `CLAUDE.md` · Status: `docs/STATUS.md` · Licences: `docs/LICENSES.md`
- Render: `gh workflow run render.yml -f comp=Smoke -f chunks=4`
- No videos or large assets are stored in git; assets come from the `assets-v1` Release.
