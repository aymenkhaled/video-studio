# Episode 002 "Why Rome Destroyed Carthage" + Clarity Kit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 12–15 min History-in-Maps episode on the Third Punic War that a zero-background viewer fully understands, built on a reusable, opt-in Clarity Kit in the map engine.

**Architecture:** Research and script come first (they decide what the kit must show). Pure logic (years-ago, caption cues, label layout) lives in one import-free TS module with `node:test` tests; React pieces are opt-in props/overlay types on the existing `HistoryEpisode`/`MapShot`, so 001-Hannibal renders unchanged. Rendering, stills and QA run only in GitHub Actions (`render.yml`).

**Tech Stack:** Remotion 4.0.543, React 18.3, d3-geo 3.1.2, world-atlas 2.0.2 (Natural Earth, public domain), Kokoro TTS via `packages/audio/soundtrack.py`, Node 22 `node:test` with `--experimental-strip-types`.

**Spec:** `docs/superpowers/specs/2026-11-13-002-carthage-design.md`

## Global Constraints

- Deterministic: Remotion `random(seed)`, frame-derived motion; never `Math.random()`/`Date.now()`. No animated blur / SVG turbulence.
- 1920×1080, 24 fps, voice Kokoro `am_michael` speed 0.95 (same as Hannibal), −14 ±1 LUFS, true peak ≤ −1.5 dBTP.
- Length 12–15 min ≈ 1,900–2,200 narration words. Every on-screen number has a source row in `sources.md`. Violence told, never shown graphically; nothing graphic in the first 7 s.
- Licences: PD/CC0/CC BY/OFL/MIT/BSD/Apache only; each new asset gets a row in `docs/LICENSES.md`.
- All Clarity Kit features are opt-in; with no `clarity` prop, `HistoryEpisode`/`MapShot` output must be byte-for-byte the same as today.
- Fixed "now" year for "years ago": **2026**. No year 0: `yearsAgo(-149) = 2026 + 149 − 1`.

## Review Focus
1. Hannibal regression: `Hannibal` comp without `clarity` must not gain captions, legend or modern borders → Task 4 test asserts `HistoryEpisode` ignores clarity pieces when prop absent (typecheck + a stills run of `Hannibal` at 3 frames compared visually in Task 10).
2. Very long caption words / a single sentence > 2 lines → `captionCues` must split into several cues, never overflow → test in Task 3.
3. Labels near the frame edge or stacked 3+ deep (army marker + city + region at one spot, Hannibal weakness #2) → `layoutLabels` keeps every box inside the frame and non-overlapping, or hides the lowest priority → test in Task 3.
4. Missing `timing.json` (local preview / stills fallback) → captions still appear from estimated timings → Task 4 step.
5. Scenes longer than 15 s without a new visual event (viewer boredom) → Task 9 validator fails the episode.

```ts
import {test} from 'node:test';
import assert from 'node:assert/strict';
import {yearsAgo, agoLabel, captionCues, layoutLabels} from '../src/map/clarity-logic.ts';

test('years ago, no year zero', () => {
  assert.equal(yearsAgo(-149), 2174);
  assert.equal(yearsAgo(-146), 2171);
  assert.equal(yearsAgo(1979), 47);
  assert.equal(agoLabel(-149), 'about 2,170 years ago');
  assert.equal(agoLabel(1979), 'about 50 years ago');
});
test('caption cues respect width, line count, order, sentence breaks', () => {
  const text = 'Carthage paid. Rome was still afraid of a city that kept getting richer every single year, and Cato said so in the Senate again and again.';
  const words = text.split(' ').map((w, i) => ({w, t: i * 0.3, end: i * 0.3 + 0.28}));
  const cues = captionCues(words);
  assert.ok(cues.every((c) => c.lines.length <= 2 && c.lines.every((l) => l.length <= 42)));
  assert.equal(cues.flatMap((c) => c.words.map((x) => x.w)).join(' '), text);
  assert.deepEqual(cues[0].lines, ['Carthage paid.']); // a sentence end closes a cue
  assert.ok(cues.every((c, i) => i === 0 || c.t >= cues[i - 1].end - 1e-9));
});
test('a single 60-char token is split onto its own cue, not dropped', () => {
  const long = 'x'.repeat(60);
  const cues = captionCues([{w: 'a', t: 0, end: 1}, {w: long, t: 1, end: 2}]);
  assert.ok(cues.some((c) => c.words.some((w) => w.w === long)));
});
test('labels: no overlaps, inside frame, priority never moves', () => {
  const boxes = [
    {id: 'army', x: 900, y: 500, w: 160, h: 40, priority: 3},
    {id: 'city', x: 920, y: 510, w: 180, h: 36, priority: 2},
    {id: 'region', x: 910, y: 505, w: 300, h: 50, priority: 1},
    {id: 'edge', x: 1850, y: 1060, w: 200, h: 40, priority: 1},
  ];
  const out = layoutLabels(boxes, {w: 1920, h: 1080});
  const army = out.find((p) => p.id === 'army')!;
  assert.deepEqual([army.dx, army.dy, army.hidden], [0, 0, false]);
  const shown = out.filter((p) => !p.hidden).map((p) => { const b = boxes.find((x) => x.id === p.id)!; return {...b, x: b.x + p.dx, y: b.y + p.dy}; });
  for (const a of shown) { assert.ok(a.x >= 0 && a.y >= 0 && a.x + a.w <= 1920 && a.y + a.h <= 1080, a.id); }
  for (const a of shown) for (const b of shown) if (a !== b) assert.ok(a.x + a.w <= b.x || b.x + b.w <= a.x || a.y + a.h <= b.y || b.y + b.h <= a.y, `${a.id}/${b.id}`);
});
```
