# B003 — Image / licence research: "The Biggest Living Thing"

Scope: real still images and satellite imagery for a monetised Scale & Science video. Research date: `2026-11-18`. No local rendering; this is a research deliverable only.

## Rules used

- Allowed licences: **Public Domain**, **CC0**, **CC BY**, **CC BY-SA**.
- Rejected: NC, ND, unknown/ambiguous, ESA/Google Earth Studio/Unsplash/Pexels under repo policy.
- **CC BY-SA options are marked `SA-FLAG`.** User allows them if marked separately; repo policy rejects them (`CLAUDE.md:25`, `PLAYBOOK.md:294`). Do not use an SA row without Aymen sign-off.
- Commons licences were checked on the actual file pages via `https://commons.wikimedia.org/w/api.php?...&prop=imageinfo&iiprop=extmetadata|url|size` (`LicenseShortName`, `License`, `Artist`) on `2026-11-18`. File page URLs are given in every table row.
- Satellite licences are quoted/verified in `docs/research/B003-satellite.md` and reused here.

Attribution columns give the exact line to place in the description/credits; when legally optional it is marked "optional". For on-screen credit use the same short credit.

## Rejected / do not use

- EOX 2018–2025 layers: CC BY-NC-SA 4.0 / non-commercial — rejected ([EOX FAQ](https://cloudless.eox.at/documentation/faq), accessed `2026-11-18`).
- Esri World Imagery: commercial-use ban — rejected (see `B003-satellite.md`).
- NOAA Ocean Exploration 2015 dive-log URL `https://oceanexplorer.noaa.gov/okeanos/explorations/ex1502/logs/apr28/apr28.html`: 404 on `2026-11-18`; use the Commons PD file pages instead.
- NPS General Sherman page `https://www.nps.gov/seki/learn/nature/sherman.htm`: photo credits present but no explicit licence line; use Commons CC0/PD files instead.
- Unsplash/Pexels-derived files: repo policy rejects platform terms even where a Commons file page says CC0; only use with Aymen override.
- Any NC, ND or unknown licence found during the searches: rejected.
